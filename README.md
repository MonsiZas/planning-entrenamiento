# Mi Planning de Entrenamiento

Una web para crear tu plan de entrenamiento semanal.

**Úsala aquí:** https://monsizas.github.io/planning-entrenamiento/

## Qué hace

- Crea un plan para tu semana según tu objetivo, tu nivel, tus días y dónde entrenas (gimnasio, correr o casa).
- Explica cada ejercicio. Algunos ejercicios cambian cada semana.
- Apuntas tus kilos, repeticiones, carreras y tu peso.
- Ves tu progreso con gráficas.
- Descargas una copia de tus datos y la cargas en otro móvil u ordenador.

## Tus datos

Todo se guarda solo en tu navegador. No hay cuentas ni servidor. Nadie más ve tus datos.

## Aviso

Esta web no sustituye a un médico ni a un entrenador. Si tienes dudas de salud, habla con un médico antes de entrenar.

## Para programadores

HTML, CSS y JavaScript sin librerías. Para abrirla en local:

```
python -m http.server 8765
```

Y entra en http://localhost:8765
